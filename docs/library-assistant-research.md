# AnF Books (ThingsBook) Assistant-Style Features Research

## Current Capabilities (from main and recent commits)

- Library answers: progress, search, time left, summary
- whatWasIReading (uses Continue reading card)
- recommendBookFromLibrary (unfinished 4+ stars or tagged)
- unfinished books, what to read next, shelves
- Read-aloud support
- Kevo voice pack integration

## Leading Assistants & Ideas

Voice assistants support:
- "What am I reading?" / "Where did I leave off?"
- "How much time left in this book?"
- "Recommend a book" / "What should I read next?"
- Voice search: "find books by author X" or "search library for Y"
- Read-aloud control: start/stop/pause reading current book

Spotify-like: personalized recommendations based on history, but for books (local library only, privacy-first).
