# grok/library-voice-resume-search

Adds three library-style voice features for AnF Books (formerly ThingsBook):

1. **What was I reading?** — Reports the most recently opened unfinished book and its progress.
2. **Voice search of the library** — Filters books by spoken title, author or notes (top 5).
3. **Read-aloud progress** — Speaks current completion percentage and estimated time left for the open book.

Pure helpers with a small test. Fits the private local-first design; no network. Ready for integration into the existing voice/Kevo path and phrase list. Inspired by how leading assistants handle media libraries and resume commands, using only public behaviour descriptions.

Never pushes to main.
